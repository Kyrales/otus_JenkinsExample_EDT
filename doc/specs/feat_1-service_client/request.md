# Заявки на обслуживание клиентов

Справочник **Контрагенты** используется для отражения клиентов. В заявке надо просто выбирать контрагента из существующего справочника.

Нужно добавить возможность регистрировать обращения клиентов: кто обратился, когда, с какой проблемой и в каком сейчас статусе находится заявка. 

Примерно вижу это так:

- создаем документ **ЗаявкаНаОбслуживание**;
- в документе выбираем **Контрагента**;
- указываем дату заявки;
- пишем описание проблемы;
- выбираем статус заявки;
- при необходимости добавляем комментарий исполнителя.

Статусы можно сделать отдельным перечислением:

- Новая;
- ВРаботе;
- Выполнена;
- Отменена.

При создании новой заявки статус должен автоматически становиться **Новая**. При записи документа нужно проверить, что выбран контрагент и заполнено описание проблемы. Если эти поля не заполнены, пользователь должен увидеть понятное сообщение.

Плюс нужен отчет по заявкам на обслуживание по которым сможем увидеть все заявки.

Задача учебная простая. Результьтат это MVP решения.
